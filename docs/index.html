Guide pas à pas

Connecter une API et créer un CRUD

Un exemple avec des produits pour comprendre comment lire, ajouter, modifier et supprimer des données.

Étape 1

Lancer le projet

Ouvrez un terminal dans le dossier du projet, puis lancez :

npm install
npm run dev

Ouvrez l’adresse affichée dans le terminal, généralement http://localhost:5173.

Étape 2

Connecter votre API

Copiez .env.example dans un nouveau fichier appelé .env. Remplacez l’adresse par celle de votre API :

VITE_API_BASE_URL=https://api.maboutique.fr/api
VITE_API_ENDPOINT_PRODUCTS=/products

Le site va alors demander les produits à https://api.maboutique.fr/api/products. Après une modification de .env, relancez npm run dev.

Mode démo : les pages d’exemple appellent l’API sans compte. Si votre API exige une connexion, mettez VITE_DEMO_MODE=false et utilisez un compte de cette API.
Étape 3

Faire le CRUD, étape par étape

CRUD veut dire : créer, lire, modifier et supprimer. L’API des produits doit fournir les routes ci-dessous.

Exemple d’un produit :

{ "id": 1, "name": "Cahier", "category": "Papeterie", "price": 3.5, "stock": 20 }
1 · LIRE

Afficher la liste

GET /products

Le service demande les produits à l’API. La page affiche les éléments reçus dans le tableau.

Dans ce projet, cette étape est déjà reliée.

2 · CRÉER

Ajouter un produit

POST /products

Remplissez le formulaire et envoyez les valeurs à l’API. Exemple :

{ "name": "Cahier", "category": "Papeterie", "price": 3.5, "stock": 20 }

Après la réponse, le tableau recharge la liste.

3 · MODIFIER

Mettre à jour un produit

PUT /products/1

Le chiffre 1 est l’identifiant du produit. Envoyez les nouvelles valeurs, puis rechargez la liste.

4 · SUPPRIMER

Retirer un produit

DELETE /products/1

Après confirmation, envoyez son identifiant à l’API. Le tableau se met à jour.

Résumé : la page appelle le service, le service contacte l’API, puis la page affiche la réponse.
Étape 4

Adapter les champs à votre API

Ouvrez src/views/demo/DemoResourceView.vue et trouvez la configuration produits. Elle contient les colonnes du tableau et les champs du formulaire.

Par exemple, ce réglage affiche un champ « Nom du produit » :

{ cle: 'name', label: 'Nom du produit' }

Le nom name doit être identique au nom du champ utilisé par l’API. Si votre API utilise nom, écrivez plutôt :

{ cle: 'nom', label: 'Nom du produit' }

Le service qui envoie les requêtes se trouve dans src/services/demoResources.service.js.

Étape 5

Ajouter une nouvelle ressource

Exemple : ajouter une page « Catégories ». Faites ces trois changements :

  1. Dans src/services/demoResources.service.js, ajoutez categories: '/categories' dans la liste ENDPOINTS.
  2. Dans src/views/demo/DemoResourceView.vue, ajoutez categories dans CONFIGURATIONS, avec ses colonnes et champs.
  3. Dans src/layouts/TheSidebar.vue, ajoutez un lien de menu vers demo-ressource avec le paramètre ressource: 'categories'.

Le même service gérera ensuite la lecture, l’ajout, la modification et la suppression.

Étape 6

Partager le code avec Git

Une fois le projet relié à votre dépôt GitHub, envoyez vos changements avec :

git add .
git commit -m "Ajout de mon CRUD"
git push
Important : partagez .env.example, mais jamais le fichier .env. Chaque personne doit indiquer son propre domaine d’API.

Si ça ne fonctionne pas

Le tableau est vide : vérifiez que GET /products renvoie bien une liste.

Erreur 404 : vérifiez le domaine et la route dans .env.

Erreur CORS : l’API doit autoriser l’adresse de votre site.

La modification échoue : chaque produit doit avoir un id.
